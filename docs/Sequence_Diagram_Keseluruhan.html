Sequence Diagram Keseluruhan - Sistem e-Santri

Diagram ini mencakup proses utama dalam sistem: Login, Pengelolaan Data Santri oleh Admin, dan Pengelolaan Syahriyah oleh Bendahara.

Tips: Klik kanan pada gambar diagram di bawah ini lalu pilih "Save image as..." (Simpan gambar sebagai) untuk menyimpannya sebagai file PNG/JPEG.

Proses Autentikasi (Login) A->>UI: Input Kredensial Login B->>UI: Input Kredensial Login UI->>Server: POST /login (Kirim Data User) Server->>DB: Validasi Email & Password / Google ID DB-->>Server: Response Valid/Invalid Server-->>UI: Redirect ke Dashboard end rect rgb(255, 245, 230) Note right of A: 2. Proses Pengelolaan Data Santri (Oleh Admin) A->>UI: Mengakses Menu Data Santri UI->>Server: GET /santri Server->>DB: Query Ambil Data Santri DB-->>Server: Mengembalikan Data Santri Server-->>UI: Menampilkan Tabel Data Santri A->>UI: Submit Form (Tambah/Edit/Hapus Data) UI->>Server: POST/PUT/DELETE /santri Server->>DB: Eksekusi Query (Insert/Update/Delete) DB-->>Server: Status Query Sukses Server-->>UI: Response Pesan Sukses (Berhasil Disimpan) end rect rgb(230, 255, 230) Note right of B: 3.
